## CONTRACT for W2 (docs content)
- Files: website/content/docs/<section>/<NN-page>.md. Section slug = directory name (optional NN-
  prefix stripped and used for section order; without it a preferred list then alphabetical).
  Page slug = file name without NN- and .md. URL: /docs/<section>/<page>.
- Frontmatter: `title` (required, build fails without it), `section` (display name of the
  section), `order` (number, falls back to NN), `summary`. Flat `key: value` lines only.
- A leading `# Title` equal to `title` is dropped (the page renders the title as h1); other `#`
  become h2. h2/h3 go into the TOC and search.
- Links: `/docs/<section>/<page>` or relative `NN-page.md` / `../<section>/NN-page.md` (rewritten).
  Broken internal links FAIL the build (prerender handleHttpError: 'fail'); missing #anchors warn.
- Any page without `placeholder: true` hides all placeholder pages; W2 may delete them.
