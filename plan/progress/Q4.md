## DECISIONS (A470+)
- A470 /etc mirror in bob's namespace when /etc links into the host's Nix store (NixOS). Mounts
  only, no file content read (R-NIX-025 untouched); no mounts on other hosts.
- A471 realise failures of the evaluator's go and channel lookups are translated into cause
  classes (4003/6001/7002/7004/5001/3002) instead of 9004/9005; Nix text only in Raw (-v).
- A472 an empty (white-space) bob.lock marks the root and pins nothing; R-FW-048 unchanged for
  non-JSON content.
- A473 `bob lock` (and `bob init`) without bob.lock and .git: the current directory is the
  root when it holds bob.go. BOB-E-0002 carries a cause line with the exact fix command.
- A474 new command `bob init [dir] [--lang go|cc|rust|npm|ocaml]`: writes the quickstart
  project of the language (never overwrites; refuses a dir with bob.go/bob.lock/any template
  file before writing, BOB-E-0004), then `bob lock` and `bob gen` (go.mod, Cargo.toml,
  package.json, …). Module path `example.com/<dir>`, package from the dir name (R2 rule, x
  prefix for digits/keywords/main). Additive to SPEC §02.1 (owner wants new projects set up by
  bob itself); see NEEDS 1.
- A475 lock change lines: Go workspaces listed with their go version; sectional changes without
  names print only the ecosystem.
