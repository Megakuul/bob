## DECISIONS (A480+, owner may overturn)
- A480 Fixture migration keeps every label and release name: main-package binaries are bound to a
  typed `bob.Slot` declared in an importable bob.go (acme.API, polyglot.API, bigclosure.Big,
  svc.Sleeper) instead of moving deploy/ into cmd/<x> (that forced label and release-name
  changes in ~30 server/output tests; a release named like its binary collides with its label).
- A481 Test repositories and embedded bob.go strings migrated with the same rules (correction 99).
- A482 Fault patches refreshed for the new fixture text, same faults (correction 100).
- A483 Faults 82–92 for every new rule (correction 101); expect.json rewritten sorted by key.
- A484 New codes 1028 (`outside`, `subpackage`) and 1029; 1001 gains variant `pin`, 1024 `R8`;
  1027 left reserved for the open I-B32 proposal; compile-error hints stay under 1020.
  codes.go changed as data only (needed to keep code table, lock, golden and docs consistent).
- A485 Guard design: unclassified raw strings fail hard; the audited violations are red until
  fixed; the allowlist and violation list are protected; the docs locality test waits for the
  generated surface (docs and API change together, AGENTS §5.9) so the docs stage stays green.
- A486 Budgets B-098…B-103 as Appendix B rows (generator-owned budgets.json; tools count 97→103).
- A487 cpp-lib's binary is `//tool:ringtool` (correction 105).
- A488 Pipeline `[]bob.Pattern` literals are allowed label strings (correction 106).
- A489 Generated handles are sealed struct variables with role methods (`nixpkgs.Openssl.Lib(p)`),
  not typed string constants (a constant would convert from `"gcc"`) and not per-role functions
  (doubles the surface); writes to framework variables are rejected by rule R8.
- A490 Role machinery in `pkg/nixpkgs/nixext` (small, L1, refused by R7 in bob.go), `pkg/nixpkgs`
  holds aliases + the generated file: ecosystems do not compile the generated file.
- A491 Generator at `cmd/nixpkgsgen` (root module, like cmd/bob-builder/genbuilders); snapshot at
  `cmd/nixpkgsgen/snapshot/<rev>.json.zst`, outside pkg/ so the embedded framework zip stays small.
- A492 Output constants are `Out`, `OutBin`, `OutDev`, `OutLib`, … so `nixpkgs.Lib` stays undefined
  and old code fails with a clear "undefined: nixpkgs.Lib" + typed hint.
- A493 Pin tracking without a lock schema change: `lock.DefaultRev` is the default pin of new
  locks; the surface revision is compiled in (`nixext.SurfaceRev`); missing attribute → 1001 `pin`.
- A494 Registries get no generated surface: names are written once in declaration constructors
  (`Require`, `Crate`, `Dep`, `Alias`, `Opam`, new `Indirect`) returning handles; options take
  handles; resolved-namespace names (features, findlib, pkg-config modules) stay validated strings.
- A495 `proto.LibraryOpts.Root` removed (derived import root) — the only option naming a directory
  outside its package.
- A496 Go: a Go package needs a bob.go only to declare a binary, C library, cgo deps or a test
  set; `Tests(TestOpts{Recursive: true})` covers the caller's region and stops at subpackages.
- A497 Fault patches were verified with `git apply --check` inside private copies under
  /var/tmp/Q1 (not a repository; no git command ran in the shared repo).
- A498 C/C++ unit = library, binary or External; tests are not units (they belong with the code
  they test, like Go's _test.go).
