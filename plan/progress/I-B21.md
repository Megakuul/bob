### So that it cannot happen again (proposal for AGENTS.md §7 / the coordinator)
1. A unit never restores, extracts, checks out, rsyncs or copies a snapshot over shared
   directories (`tar x`, `cp -a`/`-r` onto the tree, `rsync`, `git checkout/restore/stash`).
   Snapshots, rewrites and "start over" runs happen in a private copy
   (/var/tmp/<unit>/repo, as I-M8a/I-M11a do). Results go back only as the unit's own files,
   one path at a time.
2. Mass rewriters (AST tools, sed over packages) write only files the unit owns; a rewriter
   that has to touch other owners' files runs while those owners are idle and lists the files
   in its report.
3. Commits stage named paths (`git add <files of the unit>`), not `git add -A`, so one unit's
   stale tree cannot be committed under another unit's name. A pre-commit check could refuse a
   commit that changes files outside the committing unit's ownership list.
