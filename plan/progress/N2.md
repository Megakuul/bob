## DECISIONS (A450+)
- A450 root bob.go copies outside /src (see row 4).
- A451 a repository without root go.mod evaluates with an inferred module path; SPEC has no rule
  for the path: imports of own bob.go dirs, else the directory name ("bob lock" then writes the
  root go.mod, A271). IR of two checkouts at different paths differs only before go.mod exists.
- A452 `go 1.26` == `go 1.26.0` in drift explanation (adoption of hand-written go.mod).
- A453 builder table hash split by "." (generator side; builders.go must be regenerated, NEEDS).
- A454 bob dev command lookup in the dev environment first.
- A455 CLI relative labels and the `//dir` short form resolved in pkg/cli.
- A456 `bob lock --offline` semantics (row 7b).
- A457 Go `--update` semantics kept (protected TestRCLI010Lock), `--update` all made consistent.
- A458 test excerpts without protocol lines, with the failed cases' output.
- A459 C/C++ dev share: gcc + clang-tools; dev packages deduplicated by store path.
- A460 dev servers stay documented as unimplemented (M9.6 is a feature milestone).
