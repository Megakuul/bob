## DECISIONS
- D-IB11-1 bidx/running lists every non-terminal build (pending/queued with zero `sa`), plus terminal
  builds until their jobs are finalised and statuses delivered: one GC per pass finds all work (no LIST).
- D-IB11-2 Every build runs evalbuild closure jobs (one per platform); the eval + batch split (S14
  planner) is not used yet: batch jobs need a realise-by-drv entry in pkg/engine/build. bnodes holds
  per-job package nodes with states (no bitmaps).
- D-IB11-3 No ProjectService exists: Projects is an interface; the server uses AnyProject (any valid id,
  no linked repo), so commit statuses and git checkouts need ProjectService (NEEDS). Upload (remote)
  builds work.
- D-IB11-4 The build selection travels in JobSpec.Targets as `@…` selectors (JobSpec has no field for the
  trigger); labels never start with "@".
- D-IB11-5 Concurrency lane = ref; all tags of a project share one lane (R-PIPE-005 (2) needs two tag
  builds to queue). Mode = older build's evaluated pipeline concurrency (queue > supersede > parallel),
  else per-ref default; release pipelines never superseded.
- D-IB11-6 Job ids `<buildID>.j<nnnn>`; a retry attempt (infra / blocked promotion) is a new job id with
  Attempts carried; staging prefix = JobSpec.Staging (`staging/<b>/<j>/`) + attempt.
- D-IB11-7 Worker engine store: /nix bind at <home>/nix + root-mode nix.conf copied over the engine's
  dev profile after store.Open (needs a worker mode in pkg/engine/store, NEEDS).
- D-IB11-8 Staging decides "served upstream" by HEAD https://cache.nixos.org/<hash>.narinfo from the worker
  process; unreachable → the path is staged (orchestrator verifies). bob's own cache is not asked.
- D-IB11-9 Evaluation reports are bound to the signed result by JobResult.EvalSHA (new field 9).
- D-IB11-10 Failed builds keep running jobs until they end (only queued ones cancelled), per §05.6.2.
