## DECISIONS (A520+)
- A520 Ecosystem public fields/params take `nixext.Attr` (identical type to `nixpkgs.Attr`, an
  alias): the ecosystem packages import only nixext, never the generated file (plan step 1/2).
- A521 Go `Tests` without Recursive keeps the old one-package semantics: one unit labelled
  //<dir>:<Name> (default go_test); with Recursive a set //<dir>:<Name> (default tests) of units
  //<pkg dir>:go_test (needed by svc/it //it:it, //it:it2, //it:never and acme's api_tests).
- A523 Q3 test-correction numbers start at 130 (107–129 left to Q2, which ran concurrently).
- A524 `Indirect` handles are not dependencies: using one as a Dep is a definition error naming
  its position (rust/npm/ocaml); an option taking a nil handle is a definition error.
- A525 Literal nixpkgs attributes inside bob's own ecosystem packages are generated handles
  (plan step 7); computed ones (go_<minor>, rustc.unwrapped, toolchain, OCaml set members) use
  nixext.New. The Go toolchain default stays computed from ModuleOpts.Go.
- A526 The rust bop hint change is a builder behaviour change: BuilderVersion 18 (job goldens
  regenerated with it).
- A522 `Indirect` handles record their bob.go position (runtime.Callers, first bob.go frame) in
  the spec as an omitempty field, so IR of repositories without Indirect is unchanged.
