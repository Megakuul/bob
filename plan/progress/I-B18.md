## DECISIONS
- D-IB18-1 OCI tokens carry `prj` (projects with RegistryService/GetRepository, "*" = all) and `kid`
  besides sub/exp/acc: /v2/ sees only the token, so per-object visibility (§6.6.2) is decided from
  it; revocation takes effect at the latest when the 900 s token expires.
- D-IB18-2 HMAC keys: index ocihmacs/all + seeds ocihmac/<kid>, unsealed in the control bucket (as
  D-IB9-2), created by Ensure at start or on demand (no key controller); 30 d signing life.
- D-IB18-3 The /v2/ 401 challenge has no error="insufficient_scope": podman/skopeo turn that into
  "requested access to the resource is denied", while R-REG-003 (protected test) wants
  "unauthorized"; the body is UNAUTHORIZED, missing and not-allowed answer identically.
- D-IB18-4 Build tag = the build id ("b-01J…"), not "b-<build id>"; ≤ 500 build tags per repository.
- D-IB18-5 Images hook re-verifies a staged blob even when it is already served before adding the
  job's project (same reasoning as D-IB9-6).
- D-IB18-6 Releases are published synchronously in the build controller's finish (idempotent,
  resumed by the next pass): the build's success guard (§05.6.4) and the "already exists" build
  failure need the outcome before the build ends; no separate release controller/queue (no LIST).
- D-IB18-7 Every release enters ridx at creation (not only public ones, §05.6.4 says "ridx Set if
  public"): the registry list, the registry-wide ListReleases and Retained need private ones too;
  readers filter by visibility.
- D-IB18-8 Manifest project "" is accepted (built without a server project); a different project is
  rejected. The version must be semver (ResolveRelease) and equal the tag without "v".
- D-IB18-9 UpdateRelease/DeleteRelease etag optional (D-IB4-3). DeleteRelease of a pending/
  publishing release → FailedPrecondition; repeating DeleteRelease finishes an interrupted cleanup.
- D-IB18-10 /r/ with an invalid credential → 401 (as /nix/), not 404.
- D-IB18-11 Release labels: pipeline definitions name releases ("api", pkg/bob Pipeline.Releases);
  PipelineRun gets ReleaseLabels (cbor rls) so finish knows them without the report.
- D-IB18-12 imagePromotion replaces the promotion controller pass of cacheParts (wiring rule: only
  parts_registry.go + one parts.go line); the promoter is identical plus the Images hook.
