# Gate H rulings (2026-10-22)

Owner instruction (chat, 2026-10-22): "read all harness data and understand the spirit of the
project (like where it wants to go) and based of that resolve the conflicts". The coordinator
resolved every item of `docs/review/owner-items.md` with AGENTS.md §2 (decision principles) and the
requirements vision. Each ruling is recorded in `plan/decisions.md` as A42+ so the owner can
overturn it. Sources: SPEC.md is generated from `spec/*.md`; edit the sources, then regenerate.

Method: where SPEC text contradicts itself, the measured evidence (spikes, recorded goldens, real
backend behaviour) and the more specific text (acceptance of one requirement) beat the general
text. Where a test is stricter than the SPEC can support, the test changes only to what the SPEC
states, never to weaker than that.
